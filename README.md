# Boxing Vision

Локальный инвесторский прототип анализа боксёрских трансляций. Приложение принимает видеофайл, отслеживает двух бойцов, выделяет кандидаты ударов и создаёт размеченный ролик, статистику, таймлайн и экспериментальную оценку боя.

> Это исследовательская аналитика, а не официальная судейская система. Попадания, блоки, нокдауны, impact proxy и победитель всегда показываются с уровнем уверенности.

## Быстрый запуск на macOS

Требования: macOS, Python 3.11+ и FFmpeg с `libx264`. Если FFmpeg отсутствует:

```bash
brew install ffmpeg
```

1. Дважды нажмите `start.command` или выполните `./start.command` в Terminal.
2. Откройте `http://127.0.0.1:7860`.
3. Загрузите MP4, MOV или MKV, задайте параметры боя и нажмите «Запустить анализ».

Первый запуск скачивает открытые веса RTMPose. Обработка выполняется только локально. Приложение не скачивает ролики по YouTube-ссылкам.

## Результаты

Каждый запуск создаёт каталог `runs/<job-id>/`:

- `annotated.mp4` — ролик с боксами, позами, событиями и HUD;
- `events.json` — таймкоды и атрибуты событий;
- `summary.json` — статистика, раунды и экспериментальный победитель;
- `clips/` — короткие эпизоды вокруг ударов;
- `analysis.log` — технический журнал обработки.

## Разработка

```bash
.venv/bin/python -m pytest
.venv/bin/python app.py
```

Базовый стек: RTMLib/RTMPose, OpenCV, ONNX Runtime, FFmpeg и Gradio. Для закрытого прототипа сознательно не используется Ultralytics.

Источники и контрольные суммы открытых моделей перечислены в `THIRD_PARTY_NOTICES.md`. Приложение проверяет SHA-256 кэшированных lightweight-checkpoint перед анализом.
